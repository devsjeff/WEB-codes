1. Use headings first
# Project Name

## Category

### Topic

Think in levels:

Project
 └─ Category
     └─ Resource
2. Use tables for links

Instead of:

React Quick Review - link
Basic Topics - link

use:

| Resource | Link |
|----------|------|
| React Quick Review | ... |

GitHub renders this very cleanly.

3. Keep one emoji per section
🌐 Web
⚛️ React
🗄️ Database
🚀 Goal

Too many emojis make a README harder to scan.

4. Write README top-down

Always use this structure:

Title
↓
What is this?
↓
Categories
↓
Links
↓
How to use
↓
Future plans
